项目名称:ViberFix 哪里不爽点哪里

问题与场景:Vibe coding 让非前端也能"说"出页面,但视觉反馈无法结构化回到研发流程:用户不爽却说不出哪里不对,写不出 Agent 能执行的精准指令,反馈散落截图与聊天。

核心解决方案:扩展像检查元素一样框选元素/区域,自动截图、生成选择器、猜语义,附带术语进入桥接队列;以 AgentTeams 为基点,五个 Agent 闭环:哨兵聚合反馈、调度拆解分派、巧匠根因定位与自动编码、验收跑 build/lint 并生图预览叠加对比,人工确认、沉淀归档轨迹并演进术语库。

创新点与差异化:"哪里不爽点哪里"把视觉反馈变成结构化任务输入;术语库让不懂设计的用户也能精准指挥;同一队列以 Skill/MCP/DSH 插件三形态同契约接入,连接层与能力层解耦;预览叠加对比形成天然人工审批点,改码独立提交可回滚。

开放/复用价值:仓库公开、桥接零依赖;QwenWork skill、cran-code(MCP)、DeepSeek Harness(插件)三路径即用;术语库独立可分发。

当前进展:扩展/桥接/skill/MCP/DSH 插件均已实现,单测与全链路通过,仓库 github.com/NLPark-Cran/viber-fix。
